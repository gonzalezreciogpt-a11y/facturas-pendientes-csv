Control de incidencias de servicio en Excel

Cuando una petición queda repartida entre correos y mensajes, cuesta saber qué se prometió y qué vence primero. Una tabla por incidencia permite revisar compromisos y cierres sin implantar un sistema complejo.

Los datos mínimos de cada caso

Usa una fila por incidencia y conserva un identificador único. Así podrás corregir el estado del mismo caso sin duplicarlo. Estas ocho columnas son suficientes para un seguimiento por fechas:

Si el caso requiere varias intervenciones, anota el historial en tu sistema habitual. Esta tabla registra el compromiso y el cierre, no reemplaza un registro detallado de conversaciones.

Cómo clasificar un vencimiento

  1. Si existe fecha de cierre real, el caso está cerrado. Si se cerró después del compromiso, márcalo como cerrado tarde.
  2. Si sigue abierto y el compromiso ya pasó, está vencido.
  3. Si el compromiso es hoy, muéstralo aparte como vence hoy.
  4. Si vence entre mañana y dentro de siete días, usa próximos 7 días.
  5. Los demás casos abiertos quedan pendientes.

La diferencia entre «vencido» y «vence hoy» evita tratar como incumplido un compromiso que aún termina hoy. En la guía se usan días naturales; si tu contrato habla de horas laborables o festivos, necesitas una regla distinta.

Ejemplo ficticio

El 9 de octubre se revisan tres casos. INC-001 se abrió el día 5, se prometió para el día 8 y aún no está cerrado: figura vencido con un día de retraso. INC-002 se prometió para el 16 y sigue abierto: entra en los próximos siete días. INC-003 se prometió para el 7 y se cerró el 8: figura cerrado tarde con un día de retraso. Quedan dos casos abiertos, uno vencido y dos días de retraso sumados entre el abierto y el cerrado tarde.

Fórmula sencilla para el estado

Si F2 contiene el compromiso, G2 el cierre real y J2 el estado, escribe esta fórmula en J2 y cópiala hacia abajo:

=SI(G2<>"";SI(G2>F2;"Cerrada tarde";"Cerrada");SI(F2<HOY();"Vencida";SI(F2=HOY();"Vence hoy";SI(F2<=HOY()+7;"Próximos 7 días";"Pendiente"))))

La fórmula presupone que F2 contiene una fecha válida. Antes de usar el resultado, comprueba que el ID no esté repetido, que apertura y compromiso estén completos, que el compromiso no sea anterior a la apertura y que el cierre real no sea futuro. Una fecha escrita como texto puede dar un resultado engañoso.

Días de retraso

Si G2 tiene cierre, compara G2 con F2. Si no, compara hoy con F2. En ambos casos evita valores negativos:

=SI(G2<>"";MAX(0;G2-F2);MAX(0;HOY()-F2))

Un cierre exactamente el día comprometido da cero días de retraso. El indicador total suma días de casos aún abiertos y de cierres tardíos; no representa el tiempo medio de resolución.

Rutina de revisión que sí se puede mantener

  1. Al recibir un caso, asigna ID, responsable y fecha de compromiso. Si no se ha acordado un plazo, acláralo antes de completar esa columna.
  2. Al empezar el día, mira primero vencidos, después los que vencen hoy y luego los próximos siete días.
  3. Cuando se resuelva, registra la fecha real. Revisa de forma periódica los cierres tardíos para encontrar causas repetidas.
  4. Corrige las filas incompletas o incoherentes antes de interpretar los totales.

La prioridad sirve para ordenar dentro de cada grupo. No conviertas automáticamente «Alta» en una promesa de un día: el plazo debe reflejar el acuerdo real.
